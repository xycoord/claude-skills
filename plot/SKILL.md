# Plot

Conventions for producing consistent, readable matplotlib figures.

Before generating any plots, read `references/plotting.md` in this skill directory.
It contains detailed conventions for colours, layout, bar charts, heatmaps, baselines,
and error bars. Following these conventions ensures figures are consistent across
experiments and reports.

Does a probe trained on instructed lies catch other kinds of lie?

ModerateNew 16 Nov

A probe trained on instructed lies scores near chance on sandbagging: AUROC 0.54 vs chance 0.50.

Result

No skyline yet. No probe has been trained on sandbagging, so the best reachable score on this set is unknown.

Precision and recall are for the lie class, at the threshold set on instructed lies.

Method

The last-token probe, trained only on instructed lies, is scored without retraining on three test sets. Only the test data changes.

  1. TrainInstructed lies, train split n = 2,400, 50% lies
  2. ProbeLogistic regression, layer 16, last-token readout
  3. TestHeld-out instructed lies, harm-pressure v2, sandbagging n = 600, 1,180, 212
Confidence

3 seeds agree, and the same probe reaches 0.93 on held-out instructed lies. Moderate, not strong: one model and one small sandbagging set.

Caveats

The sandbagging set is small (n = 212), so its 95% interval is 0.46–0.62.
